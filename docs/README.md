## 约定

- 业务设计写在本目录，不写进根目录 README 或 AGENTS.md；框架通用的约定才写进 AGENTS.md
- 设计稿数据均为 Mock，仅用于确定页面结构、交互与接口契约，不作为实现依据；落地开发必须遵循 AGENTS.md 中的前后端规范
- 设计稿中的简化实现（例如筛选栏、明文展示的密码）不得照搬到正式代码中
- 业务设计与代码不一致时，以代码为准，并更新本目录文档
- 新增文档时同步更新本文件，列出文件及其用途
