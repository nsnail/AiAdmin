# scripts

辅助脚本目录，**目前没有脚本**。

与构建、代码清理、版本标签相关的脚本放在 [build](../build/README.md)，与镜像、部署相关的脚本放在 [docker](../docker/README.md)。只有不属于以上两类的一次性或运维脚本才放在这里。

新增脚本时：

- 文件名使用小写加点或连字符，PowerShell 脚本使用 `.ps1`，Shell 脚本使用 `.sh`
- 脚本头部用注释说明用途、参数和依赖，涉及生产环境的操作需说明风险与回滚方式
- 不得在脚本里写入密码、令牌等敏感信息，通过环境变量或参数传入
- 同步更新本文件，列出脚本及其用途
